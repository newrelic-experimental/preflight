**Cursor, Windsurf, and Antigravity sessions now save a cost instead of none.** Each conversation gets a byte-size estimate of its own tool input and output, priced at the default model (`config.model`). For Cursor that covers shell commands and output, MCP inputs and results, file reads, and edits. For Windsurf it covers commands, MCP inputs and results, edits, and each file read at the file's full size on disk; Windsurf sends no command output, so that is left out. For Antigravity it covers tool arguments only, since its hooks send no tool output. The estimate leaves out prompts, replies, and cache tokens, so it undercounts. These agents cannot report exact token counts today, so the estimate is the only cost these sessions carry. The estimate survives a dashboard restart, and several Cursor windows or a dashboard saving the same conversation keep every call. Hook events from Cursor, Windsurf, and Antigravity are now labelled with their platform even when the hook command sets no `MCP_CLIENT`.
