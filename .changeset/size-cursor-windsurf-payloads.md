Cursor and Windsurf tool calls now record how much they read and wrote. The hook collector sizes Cursor's shell output, MCP results, file reads and edits, and Windsurf's edits and MCP results, from the payload fields that carry them. A Cursor read or edit has no pre event, so its input size now comes from the post event. These sizes add no estimated cost yet. The size estimate covers only the session its engine owns, and no engine owns a Cursor or Windsurf conversation. A call that reports its own tokens through the hook records no output size, so a size estimate cannot count its result on top of the report. Windsurf's `post_read_code` sends no file content, so the collector sizes the read with one stat of the absolute file path, and records 0 when the path is relative, missing or not a regular file. A Windsurf edit's input size now counts its edits rather than its file path. Windsurf sends no command output, so a Windsurf command still records no output size.
