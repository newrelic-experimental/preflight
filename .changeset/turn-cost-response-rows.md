'@newrelic/preflight': minor
---

`AiTurnCost` now includes responses that no tool call claimed: the first response after each prompt, which asks for that turn's tools, and every text-only reply. Before, Preflight dropped the token report for each of them, so their cost never reached New Relic. Each one now arrives as its own row with no `tool` or `tool_use_id` and `turn_tool_call_count` set to 0. Because those responses now count, `AiTurnCost` totals rise at the upgrade by the spend that previously never reached `AiTurnCost`. On one account over 7 days, `AiTurnCost` held $14.99 of $122.48 in `AiCodingTask` spend before this change, so spend alerts or budgets built on `sum(cost_usd) FROM AiTurnCost` will see a step up. To total cost per tool, add `WHERE tool IS NOT NULL` to your query. The local dashboard and the cost figures in `nr_observe_get_cost_per_tool` are unchanged. Its `droppedTokenEvents` now counts only tool-call bursts evicted with no closing report, whose cost was lost, so it falls sharply. Responses no tool call claimed are no longer counted there, since they now reach `AiTurnCost`.
