**Cursor and Windsurf agents can report their token cost while Preflight's engine is pending, and it is saved to the conversation that made it.** Their engines stay pending, because Cursor and Windsurf hooks write no session breadcrumb. A pending engine serves every chat in the window, so it cannot keep a report itself. The tool now accepts the report and Preflight's post-MCP hook records it into that conversation, using the conversation id and arguments the hook already carries. The tool takes a new `report_id` per call, and the hook saves each `report_id` once per conversation, even when another process drains the retry. A report's thinking tokens are saved in that conversation's session file, with its input and output tokens. When no hooks file runs Preflight's collector for the post-MCP event, the reply says the report may not be saved until the hook is added. Claude Code is unchanged. It does not list the tool while pending and records its own reports in process.
