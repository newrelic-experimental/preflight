**Secrets passed as command arguments are now redacted before they reach New Relic, local storage or the dashboard.** This covers the value after `--token`, `--password`, `--secret`, `--api-key`, `--access-key` or `--auth-token`, in single-dash, underscore and `=` forms. It also covers a `mysql`, `mysqldump`, `mysqladmin` or `mariadb` password written as `-p<password>`, an `X-Api-Key`, `Api-Key`, `X-Auth-Token` or `X-Access-Token` header value passed with `-H` or `--header`, and an `aws_secret_access_key` value. The flag or header name is redacted together with its value, the same way `API_KEY=value` already was. Flags that name a file or stdin, such as `--token-file` and `--password-stdin`, are left as they are. Commands longer than the content limit (10,240 characters unless `NEW_RELIC_AI_MCP_MAX_CONTENT_LENGTH` sets another) are now cut to that limit before redaction, as tool input and output already were, so a very long command no longer stalls the hook.
